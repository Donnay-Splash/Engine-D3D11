## Agent skills

### Issue tracker

Issues live in this repository's GitHub Issues; use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five triage labels are `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: use the repo-root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.
